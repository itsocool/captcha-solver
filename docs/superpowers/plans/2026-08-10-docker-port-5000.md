# Docker Port 5000 Unification Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Docker와 FastAPI의 호스트·컨테이너·실행·헬스체크 포트를 모두 `5000`으로 통일하고 루트 `.env`의 웹 설정을 실제 실행에 반영한다.

**Architecture:** Compose는 루트 `.env`를 컨테이너 환경 변수로 주입하고, `apps/web/app.py`는 Pydantic Settings가 읽은 `WEB_HOST`, `WEB_PORT`, `WEB_DEBUG`를 Uvicorn에 전달한다. Dockerfile은 앱 진입점을 직접 실행하며 포트 값을 별도의 셸 보간이나 중복 `ENV`로 정의하지 않는다.

**Tech Stack:** Docker, Docker Compose, Python 3.12, FastAPI, Uvicorn, Pydantic Settings, uv

## Global Constraints

- Python 버전은 `3.12.*`, 패키지 관리자는 `uv`, 잠금 파일은 `uv.lock`을 유지한다.
- 호스트 포트, 컨테이너 포트, 앱 실행 포트, 헬스체크 포트는 모두 `5000`이다.
- `.env`는 이미지에 복사하지 않고 Compose `env_file`로만 주입한다.
- 새 의존성, 셸 래퍼, 별도 설정 파일은 추가하지 않는다.
- 기존 `/health` 엔드포인트와 `captcha_data` 읽기 전용 마운트는 유지한다.
