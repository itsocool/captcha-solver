## 현행 기준과 제한

- 기존에 이름이 붙은 파일은 자동 이름 변경에서 제외되지만 “신뢰도 계산”에서는 누락 예측의 대상이다.
- 신뢰도는 저장된 모델 예측에 대한 값이며 수동 입력한 정답의 정확도를 의미하지 않는다. 모델 재학습 후 기존 저장값을 일괄 갱신하는 기능은 이번 범위에 포함하지 않는다.
- 수동 확인·편집 이력은 DS-005 적용 후 성공한 저장부터 기록한다. 기존 파일명을 편집 이력으로 추정하지 않는다.
- 현행 생성 순서는 파일 mtime 기준이며 파일시스템 birth time을 사용하지 않는다.
- EXP-001~005: 기존 train 1,197장 수동 검수는 사용자 확인 사항이다. **신규 독립 평가 데이터는 아직 없음**(2026-09-24 사용자 확인). 도구 구현·수치 검사 통과를 실제 정확도 개선이나 배포 후보 확정으로 해석하지 않는다. 운영 모델 교체·웹 학습 화면 반영은 후속 범위다.
- seed·분할·설정은 고정하지만 CUDA CTC backward의 결정적 구현 부재로 비트 단위 재현은 보장하지 않는다. 결정성 경고 허용과 환경을 기록하고 3 seed 비교로 변동을 확인한다.
