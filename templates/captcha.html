API 설명 & 사용법

간단한 HTTP 엔드포인트로 이미지 파일을 multipart/form-data로 전송하면 예측을 반환합니다.

  • URL: POST /api/v1/captcha
  • 필드: image (파일)
  • 응답(예): 
    { "predicted": "3g2w6", "confidence": 0.9876 }
curl 예제 (Linux / macOS / WSL)
curl -X POST https://dev.hyperinfo.co.kr/api/v1/captcha -F "image=@/path/to/captcha.png"
PowerShell 예제 (Windows PowerShell)
$form = @{ image = Get-Item 'C:\path\to\captcha.png' }
$response = Invoke-WebRequest -Uri 'https://dev.hyperinfo.co.kr/api/v1/captcha' -Method POST -Form $form
$response.Content | ConvertFrom-Json
CMD 예제 (Windows CMD) 추후 octet-stream 지원 예정
curl.exe -X POST https://dev.hyperinfo.co.kr/api/v1/captcha -F "image=@C:\\path\\to\\captcha.png"
